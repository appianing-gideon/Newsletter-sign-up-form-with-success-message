## Overview
This challenge was to build a newsletter sign-up form that includes form validation and a success message. The form should be responsive and visually appealing, with hover and focus states for all interactive elements. The user should be able to enter their email address, submit the form, and see a success message if the submission is successful. If the user leaves the field empty or enters an incorrectly formatted email address, they should see appropriate validation messages.
### The challenge

Users should be able to:

- Add their email and submit the form
- See a success message with their email after successfully submitting the form
- See form validation messages if:
  - The field is left empty
  - The email address is not formatted correctly
- View the optimal layout for the interface depending on their device's screen size
- See hover and focus states for all interactive elements on the page

### What I learned
How to create a responsive newsletter sign-up form that includes form validation and a success message. I learned how to use JavaScript to handle form submissions, validate user input, and dynamically update the DOM to show the success message. I also improved my CSS skills by creating a visually appealing design that adapts well to different screen sizes.

How to use regex to validate email addresses in JavaScript. I found this really useful for ensuring that the user input is in the correct format before allowing them to submit the form. It was a bit tricky to get the regex pattern right, but I found some great resources online that helped me understand how to construct it properly.
